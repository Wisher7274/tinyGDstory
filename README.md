# tinyGDstory

一个基于 Godot 4 开发的轻量级、可移植剧情系统框架。
适用于需要剧情驱动，但并非完全是剧情类的游戏进行播放剧情。
支持并行动画、打字机效果、资源管理及自定义指令扩展。

![Godot Version](https://img.shields.io/badge/Godot-4.6.1+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ 特性

- **并行演出系统**：角色动作、背景切换与对话打字机效果并行执行，无需等待动画结束即可开始对话。
- **高性能 Tween 驱动**：所有动画基于 Godot Tween 系统，非阻塞且性能优异。
- **JSON 剧本格式**：简单易读的文本剧本，支持版本控制，方便编剧协作。
- **扩展性强**：支持自定义指令（Command），轻松扩展音效、震动、变量判断等功能。
- **交互优化**：支持打字机跳过、输入锁、全局 CTC (Click to Continue) 管理。
- **✨ 核心特性：帧并行逻辑**：什么是帧并行逻辑？
传统视觉小说系统通常按顺序执行每个操作：先等背景切换完成，再等角色登场完成，最后才显示对话。这会导致演出有停顿感。本框架采用并行执行：背景切换、角色登场、对话显示同时开始，全部完成后才等待玩家点击。

## 📦 快速开始

1. 克隆本仓库到您的 Godot 项目中。
2. 将 `Stage.tscn` 场景实例化到您的游戏主场景中。
3. 在 `stage.gd` 中修改初始剧本路径。
4. 按照 `Guildance.md` 编写您的剧情文件。

## 📂 项目结构

```text
├── scenes/
│   ├── Stage.tscn          # 剧情舞台主场景
│   └── object/
│       └── Character.tscn  # 角色立绘预制体
├── scripts/
│   └── Stage.gd  # 核心剧情控制器
├── source/
│   └── dialogue/           # 剧情文本文件存放处
|   └── character/          # 角色立绘差分
|   └── bgs/                # 背景图片
|   └── sound/              # 音频
|   └── font/               # 字体
└── docs/                   # 文档
```
